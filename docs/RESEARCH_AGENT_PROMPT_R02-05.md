## 二、★★ 三条硬约束（本任务的成败标准）

补到 3 个之后，若年内窗口**仍然不集中** —— **那是阴性结论，同样有价值**
（「该主题没有稳定的年内时间窗口」）。

→ **不得**为了凑出「集中」而挑选起止日期。

### 2. 补不到就如实记 `known_gaps`

若某主题**确实找不到 ≥3 个有证据支撑的历史段**，**如实写明**。
「补不到」是**可接受的交付结果**；凑数不是。
