## 1 · 定义

**有效性 = 研究增量**：使用 ThreeC 之后，研究决策发生了改变；该改变在 T 时刻可核，
且在没有工具时本来不会发生（或需要明显更多成本才会发生）。

三个必要的反例，用来校准这句话：

| 情形 | 旧口径（行情超额） | 新口径（研究增量） |
|---|---|---|
| 工具提示「冬季流感 → 2018 年同期对照」，使用者本来没想到，据此查到原始公告并发现机制不同 | 板块下跌 → 记「无效」 | **有效** |
| 工具提示「成品油调价」，使用者早已知晓，板块事后涨 3% | 记「有效」 | **增量为 0** |
| 使用者自己找到关键历史对应，工具没给 | 不记录 | **负向缺口**（最该记的一条） |

★ **板块涨跌与研究增量可以完全不相关**。行情结果既不充分也不必要。

## 2 · 验收指标（三项主指标 + 两项辅助）

| # | 指标 | 怎么测 | 判据 |
|---|---|---|---|
| 1 | **新线索率** | T 时刻冻结「此前是否考虑过该方向/对应」，事后核对是否成立 | 出现 ≥1 条**可核**的新历史对应即可记为有增量；不得靠事后回忆 |
| 2 | **研究耗时变化** | 同一问题，用工具 vs 惯常方法，各自计时 | 只记录差值与触发量，不预设阈值 |
| 3 | **事后可核性** | 工具给的每条对照是否带原始 URL / 日期 / 可复核理由 | 逐条记「可核 / 不可核 / 口径不清」 |

辅助：**负向缺口**（常规工具找到而 ThreeC 没有的对应）、**覆盖边界**（因数据不足无法研究的问题）。
这两项必须与正向指标同等认真记录；缺失它们时整份日志无效。

**cluster 纪律**：同一题材 / 同一事件 / 同一周内的高度相关线索标同一 `cluster_id`，
汇总按 **cluster 数**计，不得按条目数计。记录条数 ≠ 独立样本。

## 3 · 5/10/20 日超额的新定位

- `candidate_ledger_v0_2` 的 204 条从「效果验证」降级为**待观察窗口清单**；
- 等 2026-11-05 之后窗口成熟时按现有流程结算，属于**数据补齐**，**不是主线验收**；
- 结算结果只作**行情附注**：可回答「这条线索对应的板块后来表现如何」，
  **不得**据此写「工具有效 / 命中 / 胜率」。
- 原因（不只是哲学偏好，是实测缺陷）：候选的形成依据样例为
  `evidence_grade = NOT_DISCOVERABLE_IN_TIME`、`pit_eligible_years = 0`、
  `oos_tests = 0`、`tier = EXPLORATORY` —— 候选是用全历史统计筛出的，
  **当时不可得**；事后算得再准，也不能证明「当时能发现」。

## 4 · 内部排序 / 评分（解禁，但严格限定）

**为什么必须解禁**：不做优先级，就无法做对照（对照组与工具组都要产出「先看哪条」）；
而「帮我优先看什么」本身就是产品价值。全平权陈列会让有效性**永远不可证伪**。

| 允许 | 禁止 |
|---|---|
| 在**评估视图 / 评估记录**里给线索排优先级、算分 | 排序/评分**出现在默认页面** |
| 用历史命中率作打分依据 | 写进对外产物、当作推荐或买卖信号 |
| T 时刻冻结当时的排序，事后核对是否真更值得看 | 把分数写成「未来概率 / 胜率」 |
| 展示样本量、Wilson 区间、OOS 次数、PIT 资格 | 隐藏不确定性 |

**打分定义（唯一）**：`priority_score = Wilson 95% 区间下界`，
输入为 `pattern_discovery_v0_12` 的历史 `hit_rate` 与 `n_years`。
Wilson 下界对小样本与高不确定性自动降权，无需额外调参。
所有评估行必须带 `usage = INTERNAL_EVAL_ONLY`、`calibrated = false`、
`is_probability = false`，并逐项附 `n` / `oos_tests` / `pit_basis`。

★ **这是启发式排序，不是概率、不是预测、未校准**；它只用于生成对照实验的材料，
**不参与验收判定**。评分高低与研究增量的关系本身也是待检验的假设。

## 5 · 收口判定

| 判定 | 条件 |
|---|---|
| **无法判断** | 有效记录 < 10 条或独立 cluster < 5 → 只报告触发量、耗时与数据限制 |
| **有增量（待外部确认）** | 记录 ≥10 且 cluster ≥5，且至少 3 条 LEAD 经事后核实为新的历史对应，但无外部参照 |
| **有增量（有外部对照）** | 同上，且完成至少 1 次独立参照者对照 |

★ 「没有触发」不算成功；「行情涨了」不算有效；「工具没用」也是合法结论。
★ 若收口结论为「无法判断」，**不得**以「功能还不够」为由启动新一轮开发。
