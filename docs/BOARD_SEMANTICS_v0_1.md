# 板块可解释性登记 v0.1（2026-11-07，v0.79）

> 触发：使用者质疑「其他社会服务是什么鬼？看这个我哪知道是什么板块？个股代表也没有？」
> 本文件回答：**它是什么**、**为什么排除出精选**、**怎么 research 到不模糊**、**还差什么**。

---

## 1 · 它是什么

`BK881179` = 同花顺行业分类的**「其他社会服务」**，是分类体系里的**兜底/杂项桶**：
把无法归入更细行业的公司合并成一个编制指数（`provider=ths`、`price_type=raw`、2010 起 4,088 根）。

★ 它 12 年里有 9 个 11 月跑赢沪深300、样本外 7 次命中 0.857、历史中位超额 +3.64 pp，
统计上确实"最显著" —— 但这更可能是**成分混杂造成的统计假象**，不是可研究的产业规律。
Top 6 原先只看证据强度、没有可解释性门槛，才把它排到第 1。

库内名称含「其他 / 综合」的行业板块共 **27 个**（其他黑色家电、其他食品、农业综合、
其他化学制品…），本次全部登记，其中只有 `BK881179` 进了 G1 / Top 6。

## 2 · 排除规则（排除 ≠ 删除）

| 项 | 规则 |
|---|---|
| 硬门槛 | `interpretable == true` 才允许进精选；名称含「其他 / 综合」标 `false` |
| 保留 | 统计数字**一字不改**；仍在全量区可查；写进 `excluded_from_top6` 并给排除理由 |
| 展示 | 工作台「**三、待解释板块**」单独区：被精选挡下的直接展示，其余 26 个在折叠清单里 |
| 实测结果 | Top 6 第 1 从「其他社会服务」换成**保险**，依次为保险 / 证券 / 游戏 / 华为海思 / 水产品 / 股期概念 |

## 3 · 怎么 research 到「不模糊」

### 能查证到的（`BK881179`）

- **分类层级**：同花顺二级行业，挂在「社会服务 / 公用事业」大类下，与电力、燃气、
  环境治理、环保设备、教育并列；属民生服务类的兜底细分
  （来源：[第三方分类整理](https://zhuanlan.zhihu.com/p/1950607904064386561)，低层级资料）。
- **实际业务类型**：同花顺自家行业周报（[2026-05-22](http://news.10jqka.com.cn/20260522/c676902739.shtml)）
  列出该板块前五大上涨个股 —— 实朴检测、苏试试验、安邦护卫、联检科技、国检集团
  → 指向**检验检测认证 / 安保服务 / 其他专业服务**类公司。
- **库内校验**：这 5 只按名称精确匹配全部存在
  （`sz301228` / `sz300416` / `sh603373` / `sz301115` / `sh603060`），
  `--check` 逐条复算；当前目录记录成分数 **140**（不是成员名单）。
- **证据等级**：`EXTERNAL_DESCRIPTIVE_NOT_PIT` —— 只是**外部事后描述**，
  解释「这个桶大概装了什么」，**不是成分名单、不是历史候选池、不得用于时点判断**。

### 其余 26 个（全部补了「不模糊层」）

逐条给通用口径说明「同花顺分类兜底桶，不是单一产业」+ 排除理由 + 分类页 URL +
当前目录成分数（有则写）；并从**名称本身确定性拆出父级类目**（零编造）：
`其他电子 → 电子`、`农业综合 → 农业`、`线缆部件及其他 → 线缆部件` …
**27/27 条**都有 `inferred_parent_sector`（grade `NAME_DERIVED_NOT_EXTERNAL`），
其中 **26 条**能拆出父级；唯一「综合」一词本身即兜底，如实写「无可拆的更细父级」。
★ 这只是「属于哪个大类的兜底」，**不是成分名单**，也不代表板块只有这一类公司。

## 4 · 还差什么（不得绕过）

| 缺口 | 实测 |
|---|---|
| `CURRENT_CONSTITUENTS_UNAVAILABLE` | 同花顺板块详情页是 JS 跳转壳；成分 ajax 接口 `/thshy/detail/field/.../ajax/1/code/881179` 实测 **HTTP 401**（需 cookie / 反爬）。库内 `scan_meta` 只有 173 个**概念篮子**的成员名单，**没有任何 BK 成员** |
| `HISTORICAL_CONSTITUENTS_ACCESS_GATED` | 官方只给逐日成分数量 + 最新快照 + 调样公告，按历史日期取名单不可得 |
| `BOARD_INDEX_NOT_TRADABLE` | `BK_*` 是同花顺编制指数，不是可交易标的 |

→ 因此行业板块卡如实标 `NO_HISTORICAL_CONSTITUENTS`，**不列代表股**；
概念篮子卡的个股参照继续标「当前成分 + 基准日历对齐，**不是历史成分**」。

## 5 · 如果想彻底不模糊

1. 换**实测可解析**的公开来源取当前成分（必须逐条留 `source` 与核验状态，取不到就不写）；
2. 给「当前成分参照」强制标 `CURRENT_ONLY_NOT_PIT`（今天名单 ≠ 当时名单）；
3. 更根本的是把精选对象从「**板块 × 月份统计**」换成「**可解释的概念 / 主题**」——
   板块×月份这个对象本身就容易产出无产业含义的统计规律。属方法重构，需单独一轮。
