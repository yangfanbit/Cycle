# 分母工程可行性审查 v0.1

> 状态：**只读审查**。本轮**不创建** pulse registry、**不写入**任何数据库、**不修改** Schema 或冻结产物、
> **不启动回测**、**不运行基准战**、**不挑选「表现最好的规律」**。
> 所有数字均为本轮在 `history_scan.db` / `cycle_research.db` 上的**实测**（复现命令见 §6）。

## 1 · 先拆成三个不同的问题（观察单位不同，不得合并成一个比例）

「给历史规律加一个分母」这句话掩盖了三件完全不同的事。它们的**观察单位**、**分母定义**、
**可得性**都不一样：

| | 问题 | 观察单位 | 分母是什么 | 现状 |
|---|---|---|---|---|
| **A** | 季节性历史描述：符合规则、完整可比较的年份数是多少 | **(序列, 月份) 单元** | `comparable === true` 的年份数 | ✅ **已实现且有自洽校验** |
| **B** | 脉冲题材转化：符合预注册脉冲定义的事件中，多少被独立判定为成势 | **(题材/板块, 脉冲事件)** | 全部符合脉冲定义的事件 | ⚠️ **标签不可由数据独立复现** |
| **C** | 研究机会覆盖：所有符合研究条件的时间窗口中，多少出现线索 / 无线索 / 数据不足 | **(序列, 月份) 或 (时间窗, 可研究对象集)** | 全部符合「研究条件」的单元 | ⚠️ **需先预注册「符合条件」** |

★★ **三者不得相加、不得互相替代、不得合成一个「总体命中率」。**
A 回答「这个题材在它自己的历史里出现过几次」；B 回答「一次脉冲之后有多少延续」；
C 回答「我们到底看了多少」。把 B 的比例写成 A 的分母、或用 C 的覆盖率给 B 加权，都是错的。

## 2 · 数据能力核查（实测）

### 2.1 ★★ 最重要的发现：个股历史被 3,000 根上限截断，「覆盖 2004 年」是名义的

| 检查 | 实测 |
|---|---|
| `scan_series` 里 `stock` 的最早 `first_date` | **2004-11-04** —— 但**只有 1 只** |
| `rows >= 3000`（≈被单次 3,000 根上限截断）的个股 | **2,274 / 5,576 = 41%** |
| 个股 `rows` 中位数 | **2,381**（≈9.5 年） |
| 逐只核对（已知长历史股） | 贵州茅台（2001 上市）库内起点 **2014-06-20**、3,004 行；中国平安（2007）**2014-06-19**、3,004 行；万科A（1991）**2013-11-29**、3,004 行 |

**结论**：`history_scan.db` 的个股行情**实质覆盖约 2013-11 起（≈12 年）**，不是 2004。
任何依赖个股、概念篮子、或「全市场广度」的历史研究，**上限就是这 12 年**。

★★ 这条直接反驳了「全市场个股行情覆盖 2005 年 → 概念指数也覆盖完整」的推定：
**连个股本身都只有 41% 覆盖到 2013 年之前，且是被截断而非上市时间**。

### 2.2 板块宇宙随时间扩张（不是固定面板）

| 年份 | 有 ≥200 交易日的 `industry_board` 数 |
|---|---|
| 2010–2013 | **77 / 77 / 76 / 77** |
| 2014–2017 | 84–86 |
| 2018 | 86（当年新增 208 条序列，但只有 86 条有全年数据） |
| 2019–2025 | **202–215** |

**结论**：2010–2017 的「行业板块面板」只有 **77–86 个**，2019 年后才扩到 200+。
→ 跨年份比较时，**早期年份的可用板块集合与现在不是同一批**；子行业（`BK884xxx`）多数 2018 年后才有连续数据。

### 2.3 概念篮子：起点与个股覆盖重合，成分问题**无法在现有数据下解决**

| 检查 | 实测 |
|---|---|
| `concept_basket` 序列数 / 覆盖 | 173 只，`first_date` 中位 **2013-11-05** |
| 有 ≥200 交易日的篮子数 | 2013：**2** · 2014：**167** · 2015 起：**172–173** |
| 成员「库内首个交易日」晚于篮子起始日的比例 | 中位 **72%**（均值 71%，最大 84%） |
| 「第 50% 成员已有数据」的日期（有效起点） | 中位 **2014-03-13** |

★★ **必须说清这个 72% 不能直接当「幸存者偏差」的量化**：它**同时混入了**
① 成员当时确实未上市 ② 成员的个股历史被 3,000 根上限截断 ③ 停牌。
现有数据**无法区分**这三者（缺少真实 IPO 日期字段与上市前记录）。

**但可以确定的是**：
- 概念篮子用的是**当前**成分（`scan_meta.members:CPT_*` 是建库当时的快照，即"当前"），
  不是历史成分 —— 这一点在产物 `note` 里已写明；
- 因此篮子的 2014–2016 段**由当时已存在的少数成员合成**，与今天的篮子不是同一个对象；
- → **概念篮子不能用于跨 10 年的历史比较**，只能用于「近 3–5 年、成分相对稳定」的窗口。

### 2.4 ★★ 「成势」标签不可由价格序列独立复现

**既有定义**（`docs/HISTORICAL_VALIDATION.md` §1A）要求四项**同时**具备：

1. 一定持续性（数周以上，不是单日/数日脉冲）
2. **可识别的主题 / 题材**（市场有明确炒作主线）
3. 相对明显的市场关注度或价格表现
4. **可以解释的启动与结束过程**（说清因何催化开始、因何信号消退）

其中 **2 与 4 需要定性判断**（是否说得出一条主线、能否解释起止），
且文档明写：强度「**不设精确数学阈值**（L3 统计阶段再定量化标准）」。

**库内实际情况**：

| 检查 | 实测 |
|---|---|
| `campaigns` 总数 | **62**（2016–2025，无 2026） |
| `result` 分布 | **positive 58 · weak 4 · neutral 0 · failed 0 · unknown 0** |
| 持续时长（start→end） | 可算 55 条 · **中位 387 天** · 45/55 **> 120 天** · 最短 14 天 |
| `annual_reviews`（rule × year 评审） | **66 行** · 12 条 rule · 2016–2025 |
| 其 `status` 分布 | strong 20 · medium 35 · weak 10 · **no_clear_campaign 1** · failed/unknown **0** |
| 有 review 但**未产生 campaign** | **17 条**（其中 status=strong 的就有 7 条） |

**结论（对 B 是决定性的）**：

1. **Campaign 库几乎全是成功案例**（58/62 positive，0 条 failed）→
   若把「成势 = 进了 Campaign 库」当分母，成功率恒等于 ~100%，**没有任何解释力**。
2. **真正带负向判定的记录在 `annual_reviews` 里，不在 `campaigns` 里** ——
   这是唯一可用的分母来源，但它的单位是 **(rule, year)**，不是「脉冲事件」。
3. **该分母严重不完整**：12 条 rule × 2016–2025 共 **120 个 (rule, year) 单元，只评了 66 个（55%），
   54 个（45%）从未评审**。未评审 ≠ 无脉冲，只是「没看」。
4. Campaign 中位时长 **387 天**，而「脉冲」按定义是数日至数周 → **两者本就不是同一量级的对象**。
5. 「成势」若改由价格规则定义，则它**不再是项目的 Campaign 定义**，必须另行命名，
   否则会把「价格延续」冒充成「题材成势」。

### 2.7 ★★ 脉冲的量级与 β 污染（设计约束，不是结果）

用一组**示例参数**（仅用于估量级，**未冻结**）：连续 5 个交易日累计 ≥ +8% 记 1 次脉冲，
10 个交易日内不重复计数；区间 2023-01-03 → 2025-12-31（727 个交易日）：

| 检查 | 实测 |
|---|---|
| 参与板块 | **223** |
| 脉冲总数 | **1,888**（每板块中位 8 · 最大 21） |
| 不同起始日 | **342** |
| 按年 | 2023：294 · 2024：**1,034** · 2025：560 |
| **单日 ≥30 个板块同时触发** | **11 天**，贡献 **694 / 1,888 = 36.8%** 的脉冲 |
| 最集中单日 | **2024-02-20：155 个板块同日触发** |

★★ **这 1,888 个「脉冲」不是 1,888 个独立观察**：其中 37% 来自 11 个全市场普涨日。
若直接当作分母，「脉冲 → 成势」的转化率会被**少数几天**完全主导，且与 β 无法分离。

→ 这是设计阶段必须解决的问题（见 §3.2 的聚簇规则与相对强度方案），**不是跑完再修正的偏差**。

## 3 · 规则设计草案（**方法建议，不冻结参数**）

### 3.1 观察单位的选择与取舍

| 候选单位 | 优点 | 缺点 | 取舍 |
|---|---|---|---|
| **(板块, 月份)** | 与现有 discovery 一致、可复用 | 无法表达「一次脉冲」 | 仅用于 **C** |
| **(板块, 脉冲事件)** | 直接对应 B 的问题 | 需定义脉冲；β 污染 | **推荐**，但须加聚簇 |
| **(日期, 市场)** | 天然处理 β | 失去「哪个板块」的信息 | 作为**聚簇键**，不作主单位 |

**建议**：主单位为 **(板块序列, 脉冲起始日)**，并**强制携带 `cluster_key = 脉冲起始日`**；
汇总时**同时给「脉冲数」与「独立脉冲日数」**两个数，后者才是观察单位数。

### 3.2 定义草案（每条都需预注册）

```
脉冲（PULSE）
  起：连续 5 个交易日累计收益 ≥ θ_pulse
  止：脉冲事件窗口 = 起后 10 个交易日（仅用于切分事件，不参与判定）
  去重：同板块 10 个交易日内只记 1 次

成势（SUSTAINED，★ 价格口径，不是 Campaign）
  在脉冲起后 N_sustain 个交易日内，满足全部：
    ① 相对基准（CSI300）累计超额 ≥ θ_excess
    ② 期间创出脉冲起点之后的最高收盘
    ③ 无单日跌幅 ≤ −θ_break（趋势未被破坏）

未成势（FADED）
  窗口走完仍不满足 ①或②

数据不足（INSUFFICIENT）
  窗口内缺 ≥ K 个交易日（含停牌、序列中断）

无法判定（UNDETERMINED）
  序列起点晚于脉冲日 / 该板块当期不存在 / 基准缺数据
```

★★ **「成势」这个名字必须改**：项目里「成势」已经等于 Campaign（含定性判据）。
价格口径的延续应另名（如 **`SUSTAINED_PRICE`**），否则会与 §2.4 的 Campaign 定义混淆。

### 3.3 需要预先确定的参数（跑之前写死，跑之后不许改）

| 参数 | 说明 | 合理性证据（跑之前可用的） |
|---|---|---|
| `θ_pulse` | 脉冲触发阈值 | 用 2023–2025 面板统计「5 日累计收益」分布的分位数（如 P90/P95），**在看不到后续结果的前提下**选定 |
| `N_sustain` | 延续判定窗口 | 参考 Campaign 中位时长（387 天）会过长；建议 60 交易日，并**明说它与 Campaign 不是同一口径** |
| `θ_excess` | 超额阈值 | 与基准 60 日收益的波动率挂钩（如 0.5σ），不用「拍一个百分比」 |
| `θ_break` | 趋势破坏阈值 | 单日跌幅分位数（如 P1） |
| `K` | 缺口容忍 | 与停牌分布挂钩 |
| **聚簇阈值** | 同日 ≥ N 板块触发 → 视为 1 个市场级脉冲 | 用本轮实测的分布：11 天 ≥30 板块 → 建议 N=20~30，并**同时报告 N=10/20/30 的敏感性** |

★ 参数合理性只能由**事前的分布统计**支撑（分位数、波动率、停牌率），
**不得**用「哪个参数让成势率好看」来选。

### 3.4 覆盖不到的对象（必须逐类记录，不得静默丢弃）

| 对象 | 情况 | 处理 |
|---|---|---|
| 2010–2017 的板块 | 只有 77–86 个有全年数据 | 该期只在这 77–86 个里判定；**其余记为「当期不存在」而非「未成势」** |
| 概念篮子 | 当前成分 + 3,000 根截断 | **建议首轮排除**；若要纳入，必须单独标注成分偏差 |
| 2013 年前的任何篮子 | 只有 2 个有 ≥200 日 | 记「数据不足」 |
| 退市 / 长期停牌标的 | 库内序列中断 | 记「不可观测」，与「实测 0 次」分开 |
| 未进入任何 rule 的题材 | 12 条 rule 之外 | 记「不在观察总体内」，**不得**算作失败 |

### 3.5 如何避免事后调参与挑案例

1. **参数先冻结**：把 §3.3 的取值与脚本一起 commit，跑完只报告敏感性，**不改主参数**。
2. **不看结果选样本**：先按「板块 ∈ 2023–2025 完整面板」机械取全集，不按「有没有成势」筛。
3. **禁止「三条最好规律」**：任何按结果排序取 top-N 的做法都不允许出现在首轮。
4. **事后检测 ≠ 事前信号**：`SUSTAINED_PRICE` 是用**脉冲之后**的数据判定的，
   它只能回答「这次脉冲是否延续」，**不能**当作「看到脉冲就该进场」的信号。
5. **失败年份必须保留**：`FADED` 与 `INSUFFICIENT` 都要进汇总，不得只报成功。

## 4 · 决策

# **PARTIAL GO**

理由（按 A/B/C 分别）：

| | 判断 | 依据 |
|---|---|---|
| **A** | **GO（已完成）** | 分母已存在、自洽校验 8/8、可逐项复核；只需补一句「上限 12–13 年」的声明 |
| **B** | **PARTIAL GO（须收缩 + 改名）** | 原义「脉冲 → Campaign」**不可行**：Campaign 库 0 条失败、判据含定性项、单位量级差 10 倍以上；**改为价格口径 `SUSTAINED_PRICE` 后可行**，但必须声明它不是 Campaign |
| **C** | **PARTIAL GO（须先预注册「符合条件」）** | 4,788 个单元已可全量统计（1,300 达标 / 2,756 未达阈值 / 300 年数不足 / 432 偏短）；但「符合研究条件」必须先写死，否则分母可被事后调整 |

### 4.1 推荐的最小试点范围

```
区间：2023-01-03 → 2025-12-31（727 个交易日）
对象：行业板块 185 只（2023–2025 三年都 ≥200 交易日）
      ★ 首轮排除概念篮子（成分回溯无法在现有数据下解决）
单位：(板块, 脉冲起始日)，携带 cluster_key = 起始日
聚簇：同日 ≥20 个板块触发 → 计 1 个「市场级脉冲」，不按板块数计
预期规模：脉冲 ~1,888 条 → 聚簇后 ~342 个脉冲日（本轮实测，示例参数下）
人工判断量：估计 100–200 个「成势边界」需人工确认（看起止是否说得通）
```

### 4.2 预计需要的人工判断

| 环节 | 是否可自动 | 说明 |
|---|---|---|
| 脉冲识别 | ✅ 可自动 | 纯价格规则 |
| `SUSTAINED_PRICE` / `FADED` 判定 | ✅ 可自动 | 纯价格规则 |
| **聚簇是否合理** | ⚠️ 半自动 | 需人看「11 个普涨日」的名单是否都该合并 |
| **该板块当期是否「存在」** | ❌ 人工 | 板块宇宙扩张期（2018）前后要人判 |
| **成势边界的叙事合理性** | ❌ 人工 | 仅抽查，不做全量 |

### 4.3 最主要的选择偏差（按严重度排序）

1. ★★ **β 污染**：37% 的脉冲来自 11 个普涨日 → 不聚簇就等于把 1 个事件算成 155 个观察。
2. ★★ **板块宇宙扩张**：2018 年前只有 77–86 个板块 → 早期「脉冲率」与现在不可比。
3. ★★ **「成势」定义不可复现**：Campaign 判据含定性项；改成价格规则后**必须改名**，
   否则读者会以为验证了项目的 Campaign 定义。
4. ★ **数据截断**：个股 41% 被 3,000 根上限截断在 2014 → 任何跨 10 年的结论都不可靠。
5. ★ **幸存者偏差（概念篮子）**：当前成分 + 无历史成分 → 首轮应排除。

### 4.4 正式实施前必须确认的事项

1. `SUSTAINED_PRICE` 这个新名字与口径**是否被接受**（不能叫「成势」）。
2. §3.3 的 6 个参数取值**是否按「事前分布分位数」方式选定**（而非事后调）。
3. 聚簇阈值 N 的取值，以及是否**同时报告 N=10/20/30 敏感性**。
4. 首轮**是否排除概念篮子**（建议排除）。
5. 是否接受「结论只能是**价格延续率**，不能是**题材成势率**」这一根本限制。

★ **候选数量不是硬目标**：若聚簇后独立观察 < 50，就如实写「样本不足以给出比例」，
**不得**为了凑数量放宽聚簇或缩小阈值。
