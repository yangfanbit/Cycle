# UI_SPEC.md — UI 设计原则

## 总原则

- 风格：研究工具 / 数据可视化 / 清晰 / 克制。
- **时间轴是视觉中心。** 信息密度高但不拥挤。
- 不得演化成券商行情软件 / K线软件 / 花哨金融 dashboard。
- PE、PB、MACD、成交额、资金流等不得出现在 V1 首页核心位置（未来只属于辅助数据层）。
- 白色/浅色背景优先；桌面端 ≥1200px 体验良好；手机端横向滚动基本可用。

## 首页体验路径（必须保持）

```
打开 → 全年时间轴 → TODAY → 历史规律 → 跨年行情
     → 点击 Rule → 历史案例 → Future / Pre-heat
```

## 四层视觉区分

| 层 | 视觉 |
|----|------|
| 事件层 | 灰蓝 chip，左边框强调，固定色体系（不随行业变化） |
| 规律层 | 行业配色实心条 + 前置浅色预热区段（同色 35% 透明） |
| 历史题材层 | 行业配色 + 内描边，标签显示「季节 + 年度题材」 |
| 状态层 | 状态点（🟢当前 / 🟡提前观察 / ⚪尚未进入 / 灰已过）+ 倒计时文字 |

## TODAY

- 红色竖线（--today: #c0392b）贯穿各层，顶部 TODAY 旗标。
- 仅当视图年份 = 当前年份时显示。

## 跨年 UI

- 一条 `2026-11-01 → 2027-01-15` 的 Campaign 在 2026 与 2027 视图中分段渲染，但：
  - 两段共享同一行业颜色；
  - 年界开口端显示延续箭头（◂ / ▸），条形端部去圆角表达"延续"；
  - hover 必须显示完整日期范围 `2026-11-01 → 2027-01-15`；
  - 点击详情显示完整生命周期（完整日期、持续天数、跨年徽章）。
- 不得呈现为两个互不相关的对象。

## 交互

- hover：tooltip 显示名称 / 窗口 / 状态 / 是否跨年 / 来源。
- 点击 Rule → 右侧抽屉详情；点击 HistoricalCampaign → 行情详情；两者可互相跳转。
- 顶部 ‹ › 切换视图年份。
- 时间轴下方为「未来关注窗口」区（7/30/60/90 天分桶），统一叫「提前观察」，禁止叫「买入机会」。

## 文案红线

- 「买入 / 卖出 / 建仓 / 清仓 / 推荐」只允许出现在否定性免责声明中。
- 状态文案只允许：当前窗口 / 提前观察 / 尚未进入 / 已过窗口 / 暂无相关窗口。
- 未验证内容必须带「待验证 / 候选 / 未验证」字样。
