## 1. 问题（实测）

`src/styles.css:2635-2637`：

```css
.sm-bar.win   { background: #5a7a9a; opacity: 0.88; }   /* ← 所有主题同色 */
.sm-bar.onset { background: #c9d4de; opacity: 0.9; }
.sm-bar.rc    { background: transparent; border: 1px dashed #8a7f6a; }
```

12 行大主题的柱子全部是同一个蓝，**无法一眼分辨哪根柱子属于哪个主题**。

## 2. 设计原则

| # | 原则 | 说明 |
|---|---|---|
| 1 | **分类，不是序数** | 颜色只承担「属于哪个主题」，**不表示强弱、不表示排名**。因此 12 色必须**等距色相、统一饱和度**，**不得**做深浅渐变（否则会被读成强弱） |
| 2 | **颜色冗余于文字** | 每行**始终**显示主题名 → 颜色是**辅助**通道。色觉障碍用户不依赖颜色也能用（这是本方案可访问性的核心论证） |
| 3 | **Today 是唯一强调色** | 全图只有 Today 细红线用高饱和红 `#C0392B`，其余一律低饱和 |
| 4 | **对比度达标** | 每色对白底对比度 **≥ 3:1**（非文本对比度门槛），保证 9px 细条可见 |
| 5 | **避开纯红** | 红色已归 Today；色相从 8° 起排，避免歧义 |

**其余元素**：

| 元素 | 取值 | 说明 |
|---|---|---|
| Today 细红线 | `#C0392B` | 唯一高饱和强调色（对比度 5.44） |
| `rc`（Research Candidate） | 同主题色相的**虚线边框** + 透明填充 | 保持「未晋升」语义 |
| 共识窗口 `sm-consensus` | 主题色相的**浅色底**（≈ `onset`，更低透明度） | 与柱子同源，不引入新色 |

## 4. 实现方式（待确认后执行）

**推荐：CSS 变量 + 行内 style**，而不是写 12 条 CSS 规则：

```tsx
// themeAnnualWindow.ts 或新模块：稳定映射（同一主题恒定同色）
export const THEME_COLOR: Record<string, string> = {
  资源: '#944438', 消费: '#947238', 电子: '#889438', 汽车: '#5A9438',
  金融: '#389444', 高端装备: '#389472', 信息通信: '#388894', 国防军工: '#385A94',
  房地产: '#443894', 电力设备: '#723894', 医药健康: '#943888', 未标注大主题: '#7E858C',
};
```

- 在 `SeasonalMap` 的 `sm-bar` 上设 `style={{ background: color }}`（覆盖 `.sm-bar.win` 的默认色）。
- `.sm-bar.win` 的默认色**保留**为兜底（未匹配到主题时用中性灰）。
- **映射必须稳定**：同一主题在任何快照 / 任何年份都同色，否则会破坏「颜色 = 主题」的认知。

## 5. 风险与取舍

| 风险 | 说明 | 处理 |
|---|---|---|
| **绿色可能被读成「跌」** | 中国股市惯例 红涨绿跌；「金融/汽车」等主题落在绿区 | 颜色是**分类**且**冗余于标签**；且本图表达「历史炒作窗口」而非涨跌。若仍担心，可将绿区色相整体向青/橄榄偏移（会牺牲部分可分离度） |
| 相邻色相（30°）区分度有限 | 12 色是上限 | 采用**统一饱和度 + 标签冗余**；必要时对相邻两色做轻微明度差（代价：可能被读成序数，**不推荐**） |
| 主题名新增/改名 | 映射表会缺项 | 缺项回落中性灰 `#7E858C`，并**不报错**（诚实降级） |
