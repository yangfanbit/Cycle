## 二、★★★ 阻塞条件：**必须先做 taxonomy 轮次**（实测）

协议 §3.4 / 覆盖计划 §3.3 明写：

> 若某新族在 DB `themes` 中**不存在对应根节点** → 这是**数据决策**，
> 必须**单独轮次**处理，**不在**本任务内自动新增 taxonomy 行。

**实测**（`research/database/cycle_research.db` · `themes` 表 53 行 · 根节点 11 个）：

| 提交的 proposal | CMTR v1 结果 | 说明 |
|---|---|---|
| `R02-COAL-MT001` 煤炭 | **`UNRESOLVED_NAME`** | `themes` 表**零命中** |
| `R02-POWER-MT001` 电力（运营端） | **`UNRESOLVED_NAME`** | 「电力」不在表内；★★ 见下 |
| `R02-VACCINE-MT001` 流感疫苗 | **`UNRESOLVED_NAME`** | 「流感 / 疫苗」零命中 |
| `R02-MEDIA-MT001` 文化传媒 | **`UNRESOLVED_NAME`** | 「传媒 / 文化 / 游戏 / 影视」零命中 |

### 2.1 ★★ 「电力」的陷阱（包自己预警过，实测确认成立）

DB `themes` 表里**没有**「电力」，但有「**电力设备**」（根节点，`TH-POWER`）。
任何**字面 / 子串匹配**的口径都会把「电力」错判进「电力设备」——
**这正是 `R02-POWER-MT001` 在 `rationale` 里预警的 `CONFLICT` 风险。**

★ **CMTR v1 本身不会犯这个错** —— 它的 docstring 明确写着
「**不使用** `direct`（字面名称匹配）口径」，唯一事实来源是 DB `themes` 表。
所以它给出的答案是 `UNRESOLVED_NAME`（**taxonomy 缺口**），而不是静默归入。
**这一条要作为该 proposal 的处置依据记录下来。**

### 2.2 因此的处置

- **四条 proposal 全部判定为 `UNRESOLVED_NAME` → taxonomy gap。**
- ★ **9 条候选在 taxonomy 轮次完成前，一律不得写入 canonical `campaigns`** ——
  不是因为候选不成立，而是因为**它们归属的根节点尚不存在**。
- 新增 DB `themes` 行属**独立轮次**，需单独授权。**本次审查不执行。**

## 三、逐条审查

### #1 `R02-COAL-001` —— `ACCEPT_WITH_CHANGES`

**为什么成立**
- 3 条证据 / **3 个独立组**；含 **Tier 1 一手**（发改委 2021-10-19 干预发布会）+ 2 条 Tier 2。
- 时间结构完整：上行窗口（`DATE_WINDOW` 2021-08~09）→ **政策干预锚**（`EXACT_DATE` 2021-10-19）→ 降温窗口。
- `lifecycle`：`MAIN_RISE` + `RETRACEMENT` —— 与「上行 → 转折 → 降温」一致。
- peak 依据是 `contemporaneous` + `primary_source=true` → **可作 point-in-time 依据**（协议 §7.4）。

**要求的改动（必须记录）**
1. ★ **声明 peak 的参照物**。`2021-10-19` 是**政策事件日**，不是股价/指数高点。
   必须按既有 `peak_referent` 8 值枚举声明为 **`政策事件`**。
   → ★★ **连带后果**：参照物为政策事件时，K 线证实状态应为 **`NOT_APPLICABLE`**，
     **不得**记为 `UNCONFIRMED`（`AGENTS.md` §5.1 硬语义边界）。
2. ★ **记录与 `R02-POWER-002` 的同期独立性判定**。两段同在 2021-09~10；
   协议 §1.4 **规则 4「同一时间 ≠ 同一个 Campaign」**。包已主动提出该问题
   （`why_not` ③），须在 canonicalization 时给出闸门结论。
3. 起涨日仅到 `DATE_WINDOW`：**保留窗口**，不得为「漂亮日期」收窄（协议 §7.1）。

### #2 `R02-COAL-002` —— `DEFER`

**为什么不是 `ACCEPT`**
- **peak `UNKNOWN`、end `OPEN_ENDED`** —— Campaign 需要可核验的时间结构，本候选**不具备**。
- 跨 2022–2024，粒度粗。

**为什么不是 `INSUFFICIENT`**（协议 §4.2 三者不得混用）
- 「知道发生了什么」且 start 有 Tier 1 锚（发改价格〔2022〕303号）→ **不是资料不可考**。
- 真正的障碍是**分类 / 证据结构**层面：
  ①本段与 2022 俄乌能源价格驱动段是否应拆分；
  ②与 `R02-COAL-001` 是否属同一 ThemeCycle 的不同阶段。

**指定的缺失项**
1. 板块指数口径序列（用于界定 peak / end）；
2. 与 `R02-COAL-001` 及 2022 俄乌段的边界判定（走 Independence Gate Q1–Q5）。

> ★ 另记：本段机制（**红利重估**）与库内既有的银行高股息段属**同一机制轴、不同行业**。
> 这**不构成重复**，但须在 canonicalization 时记录为跨族机制重叠。

### #4 `R02-POWER-002` —— `ACCEPT_WITH_CHANGES`

**为什么成立**
- 4 条证据 / **4 个独立组**；**两条 Tier 1 一手**：2021-09-07 发改委复函（start 锚）、
  2021-09-28 绿电交易试点正式启动（peak 锚）。两者均 `contemporaneous` + `primary_source`。
- 机制为**电力运营商的电价与消纳预期**，与库内「电力设备」（制造端：设备需求与产能）**可分辨**。

**要求的改动**
1. ★ **声明 peak 参照物** = **`政策事件`**（2021-09-28 交易试点启动日）→
   连带 K 线证实状态应为 **`NOT_APPLICABLE`**。
2. ★★ **CMTR 边界必须显式化**：本包名称（`电力` / `绿色电力` / `绿电` / `新能源运营商`）
   经 CMTR v1 实测均为 `UNRESOLVED_NAME`，**未**落入 `电力设备` 根节点。
   该事实必须写入 canonicalization 记录 —— **不得**因名称相近而静默并入「电力设备」。
3. **end 未界定** → 明确记 `OPEN_ENDED`（本包已如此处理，**未编造终局日**，符合协议）。

### #5 `R02-POWER-003` —— `OBSERVATION_ONLY`

- 2 条证据 / 2 个独立组，**均为 Tier 3**；市场活跃窗口**仅约 2 周**；peak / end 均未界定。
- 判定依据（协议 §4.2）：**有事件、有市场反应，但不够 Campaign**。

★ 为什么**不**用 `INSUFFICIENT`：本条的障碍**不是「资料不够」而是「性质不够」** ——
「虚拟电厂概念股上涨」这类**行情事实在性质上不存在 Tier 1/2 一手来源**
（没有任何官方机构会发布「某概念板块当日涨了」），因此**补齐资料并不能改变性质**。
→ 用 `OBSERVATION_ONLY`（改变性质需**新的独立证据**，如该概念在后续年份的复现证据）。

★ 附带价值：该段与**夏季用电高峰**直接相关，是用户所关心的「时间相关性」的
一个**真实但尚不成形**的观察 —— 保留为观察记录，不进入 `campaigns`。

### #7 `R02-VACCINE-002` —— `ACCEPT_WITH_CHANGES`

**为什么成立**
- 3 条证据 / **3 个独立组**；含 **Tier 1 一手**：中国国家流感中心第 12 周监测周报

**要求的改动**

## 五、★ 侧发现（不属 R02-03，但必须记录）

**产品侧 `macroThemeOf()` 用的是 `direct`（字面名称）口径，而 CMTR v1 明确「不使用 direct」。**

实测：DB `themes` 表根节点 **11 个**，但首页季节性地图显示 **12 行** —— 多出来的是
**`航天装备`**。而 `航天装备` 在 DB 中是 **`国防军工` 的子节点**（`TH-DEFENSE-SPACE`，`parent=TH-DEFENSE`）。

| | 口径 | `航天装备` 的归属 |
|---|---|---|
| Research / CMTR v1 | themes → 沿 `parent_theme_id` **上溯至根** | **国防军工** |
| Product `macroThemeOf` | 取 `themes[role=related ?? main].name` **字面名** | **航天装备（自成一行）** |
