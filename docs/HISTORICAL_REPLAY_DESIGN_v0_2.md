## 2 · 三个事前特征（全部只用 ≤T 的当时可知信息）

| # | 特征 | 定义 | 类型 |
|---|---|---|---|
| F1 | `GATE_HIT` | 沿用 v0.82 已发布门槛：`abs(近20日相对CSI300超额) > 5.0 pp` **OR** `近20日成交额代理均值 / 前20日均值 > 1.5` | 价格侧，二值 |
| F2 | `EXCESS20_SIGN` | 近 20 日相对 CSI300 累计超额 > 0 | 价格侧，二值 |
| F3 | `INFO_EVENT_365D` | T 之前 365 自然日内，该板块序列是否至少有一条**已登记可核事件**关联。事件来源与映射见 §3 | **信息侧（非价格）**，二值 |

★ F1/F2 只用 T 及之前的行情；F3 只用 `event_date <= T` 的事件（严格不含未来事件）。
★ F3 的 `NO_COVERAGE` 不是「假」，而是**单独三态**：`0`（无事件）/ `1`（有事件）/ `NO_COVERAGE`（该板块不在显式映射表内，无法判定）。
`NO_COVERAGE` 的观察**不进 F3 分组训练**，但仍留在主分母里，计入覆盖率统计。

### 2.1 ★ 第 3 特征「算不算数」的必要条件（在看到任何 outcome 之前写死）

只有同时满足以下三条，F3 才计入「有效事前特征数」：

- C1：F3 取值 `1` 的观察占全部可比观察 **≥ 5%**；
- C2：至少有 **20 个独立冻结点**同时出现 `0` 与 `1` 两种取值（簇内有变异）；
- C3：F3=`1` 的观察分布在 **≥ 5 个不同板块序列**（不是单一板块的重复计数）。

任一条不满足 → 记为 `INSUFFICIENT_VARIATION`，**有效事前特征数仍按 2 计**，
③ 层不得因「凑了第三个字段名」而升级。判定只由覆盖率与分布计算，**不看任何收益结果**。

## 4 · purge / embargo（P2）

- **purge**：训练池只保留「结算窗口完成日索引 ≤ `T_idx − EMBARGO`」的观察。
- `EMBARGO = HORIZON = 20` 基准交易日（一次定死）。
- v0.1 用的是「完成日 < T_idx」，本轮更严：结算完成日与 T 之间至少隔 20 个交易日，
  杜绝特征窗口与训练标签窗口的邻接污染。
- `--check` 断言：任一训练观察的完成日索引 ≤ 该冻结点索引 − 20；首簇训练池必须为空；
  训练池大小随冻结点**单调不减**。

## 5 · 检验族、不确定性与多重检验（P2）

### 5.1 三个预测器（与 v0.1 可比）
| 名 | 预测概率 |
|---|---|
| `BASELINE` | purge 后全体可比观察的 `CROSS_SECTIONAL_OUTPERFORM` 频率（climatology） |
| `EX_ANTE_GATE` | 仅 F1 分组（命中/未命中）的历史频率，分组不足 `MIN_TRAIN=20` 回退 BASELINE |
| `EX_ANTE_3F` | F1×F2×F3 共 8 分组的历史频率；`NO_COVERAGE` 与分组不足 20 都回退 BASELINE 并计 `FALLBACK` |

三者都只用严格早于 T−embargo 的已结算观察；第 1 个冻结点 `p=null`，报 `INSUFFICIENT_TRAINING`。

### 5.2 预先注册的检验族（**写死 2 个主检验**）
- **H1**：`EX_ANTE_3F` 的簇均 Brier 是否低于 `BASELINE`；
- **H2**：`EX_ANTE_3F` 的簇均 Brier 是否低于 `EX_ANTE_GATE`（第 3 特征的增量）。

`trial_count = 2`；Holm-Bonferroni：较小经验 p 值对 `α/2`、较大者对 `α`（`α=0.05`）。
其余所有数字（LogLoss、校准分箱、命中率、敏感性对照）**一律描述性，不作推断**。

### 5.3 cluster bootstrap
- 重抽样单位 = **整簇（冻结日）**，有放回抽 49 个簇；`B = 2000`，`seed = 20261113`（确定性）。
- 统计量 `ΔBrier = mean_cluster(Brier_rule − Brier_ref)`（负 = 规则更优）。
- 报 95% 与 **97.5%（Holm 后）**百分位区间，以及双侧经验 p 值。
- 区间跨 0 即「无可分辨改善」，不得写成「略有改善」。
- ★ 簇内观察不独立，因此**不报逐观察 t 检验 / 不报逐观察 Wilson 作结论**。

### 5.4 DSR / PBO 的适用性（如实说明，不套用）
- **DSR** 修正的是「策略收益序列 Sharpe 在多重试验下的膨胀」，需要收益序列与试验次数；
  本产物是**概率评分**而非策略收益，没有 Sharpe，**不计算 DSR**。
- **PBO / CSCV** 需要多个候选配置在组合切分下的排名分布；本轮只预先注册 2 个检验、
  3 个预测器，**试验次数不足以估计 PBO**，显式记 `pbo: NOT_ESTIMABLE` 并写明原因。
- 替代纪律：所有配置在本文件预先注册、`trial_count` 写进产物、`--check` 断言族大小不变。

## 6 · 2010 起绝对收益敏感性对照（P2）

- 目标：`FORWARD_ABSOLUTE_POSITIVE` = 板块 T+20 相对 T 的**绝对收益 > 0**（不减基准、不减横截面中位数）。
- 日历：全库归一交易日历（不依赖 CSI300，2010 起），同样 `PRE_DAYS=60 / STEP=60 / HORIZON=20`。
- 门槛沿用数值但换口径：`abs(近20日绝对收益) > 5.0 pp` OR 放量 `> 1.5`；`MIN_TRAIN=20`。
- ★ 该轨 **β 更重、样本更长但更脏**，只报「簇间横截面命中率摆动幅度」与基准对比，
  **明确标注 `SENSITIVITY_ONLY`、不作推断、不进主结论、不用于③层判定**。
- 与主轨并排给出摆动幅度，用于验证「横截面中性化是否真的压掉了 β」。

## 7 · β 污染是否被消除（预先定义判据）

- 主轨每个冻结点给一个横截面命中率；**按设计应恒为 ≈0.5**（中位数定义使然）。
- 判据：主轨簇间命中率的**极差 ≤ 0.02**，且敏感性对照轨极差**明显更大** → 判定
  `BETA_NEUTRALIZATION_EFFECTIVE`；否则 `NOT_EFFECTIVE` 并写原因。
- ★ 这是结构性判据，不是「结果好不好」；它只说明目标定义是否去掉了市场共同因子，
  **不代表规则有了选择能力**。

## 8 · ③ 层门槛核对条件（预先写死，不因结果改）

三层能力③要求 **步数 ≥30 且事前特征 ≥3**，另加 §3.1 的校准与基准比较要求。
本轮的**升级必要条件**全部满足才允许写「③ 已建立」：

1. 步数 ≥ 30；
2. §2.1 的 C1/C2/C3 全过 → 有效事前特征数 = 3；
3. H1 在 Holm 修正后区间上界 < 0（规则显著优于 BASELINE）；
4. H2 在 Holm 修正后区间上界 < 0（第 3 特征有增量）；
5. 校准分箱单调且无极端反常；
6. `trial_count` 与实际检验数一致、无未注册的事后配置。

任一条不满足 → `validated_model: false`，三层能力③状态**保持不变**。
★ 即使 1–6 全过，也只是「一个规则的样本外证据」，仍需另行声明才能称模型；本轮不预设升级。

### 8.1 实现量化细则（同样在跑任何 outcome 之前写定）

- 第 3、4 条的「区间上界 < 0」一律指 **§5.3 的 97.5%（Holm 后）区间**，
  并要求对应 Holm 判定为 reject；两者同时成立才算通过。
- 第 5 条「校准分箱单调且无极端反常」量化为：5 箱的实际频率**非严格单调**
  （允许相邻回退 ≤ 0.05），且每箱 `|实际频率 − 平均预测| ≤ 0.20`；
  空箱不参与、但记 `n=0`。容差为判定规则的固定部分，写入产物，不按结果调整。
- §6 敏感性对照轨的 `MIN_CROSS_SECTION` 与主轨同为 **30**（保持可比），
  不足的簇跳过并计数；该轨不参与 bootstrap、不参与 Holm。
- Holm 的经验 p 值：`2 × min(P(Δ_boot ≤ 0), P(Δ_boot ≥ 0))`，截断到 [0,1]；
  两个主检验按 p 升序分别对 `α/2 = 0.025` 与 `α = 0.05` 判定。
