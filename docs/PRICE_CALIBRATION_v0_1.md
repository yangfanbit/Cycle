# 历史行情校正 v0.1（2026-11-07，v0.78）

> 触发：使用者质疑「命中率是什么意思」「板块/主题为什么不显示个股」
> 「历史行情需要真实 A 股行情校正」。本文件只记录**复核结论与边界**，
> **不改写任何历史统计产物、数据库或基准口径**。

## 1 · 先说清原本在用什么

| 对象 | 实际来源 | 是不是真实可交易行情 |
|---|---|---|
| 行业板块 `BK_881xxx` | 同花顺 `d.10jqka.com.cn` **编制指数** | 否，不可交易 |
| 概念篮子 `CPT_*` | 新浪 `gn_*` **当前成分等权自建**（`scan_meta.members:*`） | 否，当前名单回溯 |
| 基准 `CSI300` | 新浪 `sh000300`，**3,009 根 / 2014-06-20 起** | 指数点位 |
| 个股 `sh*/sz*/bj*` | 新浪真实个股日线 | 是 |
| 全部 `scan_series.price_type` | **`raw`（未复权）** | 除权日有虚假跳变 |

历史验证链路（`discover_seasonal_patterns_v0_5.py`）：
`scan_daily.close` → 月收益 → 减 CSI300 月收益 → 按「板块 × 月份」聚合
`n_years` / `median_excess_pct` / `hit_rate` → walk-forward。
**全程没用个股验证**；个股只在 105 张概念卡里作「当前成分参照」展示。

## 2 · 「命中率」的准确定义

```
hit_rate = 该板块×月份窗口在历史 n 年里，月收益 > 沪深300 月收益的年份数 / n
```

例：`其他社会服务 · 11 月` `0.75` = **12 年里 9 个 11 月跑赢沪深300**。
它是**历史描述统计**，不是事件命中、不是推荐命中、不预测未来涨跌。
`oos_hit_rate` 是 walk-forward 检验年里的同口径占比。
★ v0.78 起页面一律显示「**历史跑赢 9/12 年**」，并在折叠区给出完整定义。

## 3 · L0：真实 A 股个股交叉校验

脚本 `research/scripts/cross_check_price_v0_1.py --write/--check`，
报告 `research/research/reports/price_cross_check_v0_1.json`（调查材料目录，**不写入 `research/current/` 生产产物目录**）。

做法：取 `scan_meta.members:<CPT_*>` 当前成分 → 用 `scan_daily` **真实个股收盘**
逐交易日等权复现日收益 → 与库内 `CPT_*` 序列对照；再做「只保留已上市满 365 天成员」的变体。

| 篮子 | 重合交易日 | 与库内序列相关 | 中位绝对差 | 上市日过滤后差异 |
|---|---|---|---|---|
| CPT_hwhs | 3,108 | 1.0 | 0.0 pp | 0.0662 pp |
| CPT_scp1 | 3,163 | 1.0 | 0.0 pp | 0.0 pp |
| CPT_gqgn | 3,147 | 1.0 | 0.0 pp | 0.0 pp |
| CPT_xny | 3,159 | 1.0 | 0.0 pp | 0.0 pp |
| CPT_hwqc | 3,061 | 1.0 | 0.0 pp | 0.0588 pp |

★★ **结论**：自建篮子的**计算完全可被真实个股复现**（相关 1.0、中位差 0.0 pp）。
所以偏差**不在数字**，而在「**用今天的成分名单去回溯 2014 年**」这个对象定义
（幸存者 / 成分变更偏差）。上市日过滤只带来 ≤0.066 pp 的差异，
说明「早年少量未上市成员被计入」不是主要偏差源；**主要偏差是名单本身不可得**。

★ 行业板块 `BK_*` 无历史成分名单（`market_data.db` 无成分/名称表），
**无法用个股复现**，未纳入抽样。这是 `NO_HISTORICAL_CONSTITUENTS` 的真实原因，
不是「没查」。

## 4 · L2：中证官方基准并列（经使用者授权）

脚本 `research/scripts/build_benchmark_parallel_v0_1.py`，
产物 `research/current/benchmark_parallel_v0_1.json`，`--check` PASS。

接口：中证官网公开无 token `index-perf?indexCode=000300&startDate=…&endDate=…`。
发布日 **2005-04-08**（`docs/INDEX_DATA_FEASIBILITY_WAVE2_v0_1.md`），基期 2004-12-31=1000。

| 段 | 区间 | 行数 | `backfilled` |
|---|---|---|---|
| `BACKFILLED_NOT_PIT` | 2005-01-01 → 2005-04-07 | **62** | `true` |
| `OFFICIAL_ONLY_PIT_ELIGIBLE` | 2005-04-08 → 2014-06-19 | **2,233** | `false` |
| `OVERLAP_WITH_LOCAL` | 2014-06-20 → 2026-11-06 | **3,010** | `null` |

★ `backfilled` 是**三态**（`null` ≠ `false`）；`rows_before_publish` 由实际序列统计，不硬编码；
三段行数之和 = 官方 5,305 行。

**与库内 CSI300 对照**：重叠 **3,009** 个交易日，0.01 容差内一致 **3,009** 日，
中位差 **0.002**（小数位精度），日收益相关 **1.0**。
→ 库内基准**就是官方点位**，两者差异**仅在起点**：库内被 3,000 根上限截断到 2014-06-20。
官方另有 2026-11-06 一天而库内停在 11-05；本轮只做对照，**不追加行情**（未授权全套刷新）。

### 授权记录（分层）

- `license.state = "UNCLEAR"`、`program_verified = false`（**不由命令行开关改变**）；
- `operator_attestation.basis` = 使用者 2026-11-07 对话中明确答复「允许」。
  这只是**操作人员提交的依据**，程序未独立核验许可范围；
- 写入闸门：目标路径先 `abspath` + `realpath` 分类；
  `research/current/` 必须同时给 `--i-have-license` 与非空 `--license-basis`；
  其余路径 FORBIDDEN；**拒绝发生在任何联网 / 写文件之前**（实测无授权 rc=2）。
- ★ 本产物只落**统计量与分段**，**未落盘逐日官方点位**；
  公开可访问 ≠ 许可公开再发布，且不对外发布投资建议。

## 5 · 边界与未做的事

- **并列不合并**：不替换 `CSI300` 基准、不改 `scan_daily`、不重算
  季节性 / digest / 账本 / 雷达 / 5-10-20 日超额。因此本轮**没有 P2 全链重算**。
- **没有做 L1 复权整段重取**：L0 显示计算无误、L2 显示基准一致，
  且项目既有四条准入（来源可追溯 / 取数可复现 / 公司行为可解释 / 收益可独立核验）
  中后两条对早年高分红段 qfq 不过关 → 不为了「更正确」而改数字。
- **没有补历史成分名单**：官方只给逐日 `consNumber` + 最新 `cons.xls` + 调样公告，
  按历史日期取名单 `ACCESS_GATED`。
- 若要真正把超额口径延长到 2005 年，需要单独一轮：落盘官方逐日点位、
  重算全派生链、并声明 `BACKFILLED_NOT_PIT` 段不得用于时点判断。
