# PRODUCT.md — 产品定义

## 核心价值

```
时间 → 历史 → 规律 → 当前 → 提前观察
```

以全年时间轴为核心交互，把 A 股历史上反复出现的行业、题材、事件与行情窗口放在同一条轴上，
帮助研究者回答：现在处于什么位置、历史上此时发生过什么、接下来什么窗口值得提前观察。

## 核心对象

- 时间窗口（TimeWindow）
- 行业季节性（Seasonal Sector / Base Pattern）
- 历史题材（Annual Theme）
- 历史行情（HistoricalCampaign）
- 固定事件（Event）
- 当前观察（Observation）
- 未来关注窗口（Opportunity Radar）

## 四层时间轴

| 层 | 内容 | 语义 |
|----|------|------|
| Layer 1 | Event | 日历事实：春节、两会、财报披露期、国庆等。**事件不是规律。** |
| Layer 2 | Seasonal Sector / Base Pattern | 候选规律："这个时间附近该行业历史上值得研究"。不是保证上涨。 |
| Layer 3 | Historical Theme / Annual Theme | 具体年份的具体炒作题材。Base Pattern ≠ Annual Theme。 |
| Layer 4 | Current / Observation State | TODAY、当前窗口、提前观察、已过窗口、暂无相关窗口。 |

## 跨年行情

- 自然年只是 UI 的显示容器，不是行情生命周期的边界。
- 一场 Campaign 不得因为跨年而被人为拆开。
- `2026-11-01 → 2027-01-15` 必须是一条完整 Campaign（`season_id: "2026-2027"`, `cross_year: true`），
  在时间轴上视觉连续，两段共享颜色并以延续箭头表达。
- 跨年形态不写死：11月→次年1月、12月→次年2月、春节前→春节后等任意形态都必须支持。

## 当前产品明确不做（V1 红线）

- 实时资金流
- 实时异动监测
- AI 预测
- 自动买卖建议
- 自动交易
- 消息推送
- 股票推荐

这些属于未来阶段（见 ROADMAP.md），不属于当前 V1。

## 前瞻性分析 ≠ 确定性预测

本项目在任何阶段都禁止：

- 确定性未来预测
- 保证收益
- 个股买卖建议
- "必涨 / 必跌"等结论
- 自动交易信号

但允许（随阶段逐步开放）：

- 历史统计、历史相似案例
- 当前状态识别、时间窗口分析
- 历史条件分布、情景分析
- 前瞻性观察窗口、"提前观察"提示

UI 可以说：「未来关注窗口」「历史上该窗口的典型表现」「当前与历史案例相似度」。
UI 不能说：「未来一定上涨」。

## 首页核心体验路径

```
打开 → 看到全年时间轴 → 看到 TODAY → 看到历史规律 → 看到跨年行情
     → 点击 Rule → 查看 Historical Campaign → 看到 Future / Pre-heat
```
