> 本文件定义 ThreeC 最终产品的**是什么**与**不是什么**。
> 与根 `AGENTS.md` §1「项目初心」一致；冲突时以根 `AGENTS.md` 为准。

---

## 产品定义

# 基于历史时间轴的 A 股机会地图

用户打开产品，看到的是**一条历史时间轴**，而不是一张行情表。

---

## 核心（产品做什么）

| 维度 | 说明 |
|---|---|
| **历史时间** | 今天处于一年中的什么位置（TODAY 标记 + 365 天真实比例轴） |
| **主题** | 历史上这个时间附近出现过哪些主题 / 行情 |
| **周期阶段** | 主题如何形成 → 发展 → 转折 → 结束（Lifecycle / Peak Window） |
| **驱动因素** | 为什么启动 / 加速 / 转折 / 结束（Drivers 四问） |
| **提前观察** | 有没有提前信号（Early Signal），哪些方向值得继续研究 |

**产品价值 = 机会发现。**

产品帮助用户**发现值得进一步研究的方向**，把"历史怎么走"讲清楚。
发现之后的研究与判断，由用户自己完成。

---

## 非核心（产品明确不做）

- ❌ 基本面分析
- ❌ 技术分析
- ❌ 买卖点 / 入场时机判断
- ❌ 自动荐股 / 选股
- ❌ 价格预测 / 收益预测 / 确定性未来预测
- ❌ 买卖信号 / 自动交易
- ❌ 实时行情 / 资金流 / 异动监控
- ❌ 胜率 / 季节性评分等量化结论
- ❌ 用户登录 / 权限系统 / 后端

> UI 文案中「买入 / 卖出 / 建仓 / 清仓 / 推荐」等词，
> **只允许出现在否定性免责声明中**（如"不构成买卖建议"）。

## 关键边界声明

### 用户自己负责入场判断

**ThreeC 不提供、不暗示、不承担任何入场判断。**

- 「提前观察窗口」≠「买入时机」。
- 「历史上这段时期出现过机会」≠「今年会出现机会」。
- 「Early Signal」= 研究层信息，**不是交易信号**。

用户自行负责：基本面研究、技术面研究、个股选择、入场时机与仓位。

### 前瞻性分析 ≠ 确定性预测

**禁止**：确定性未来预测、保证收益、"必涨 / 必跌"、自动交易信号。

**允许**：历史统计、历史相似案例、当前状态识别、时间窗口分析、
历史条件分布、情景分析、前瞻性观察窗口、"提前观察"提示。

即使未来完成统计验证，展示的也是**"历史统计特征"**，不是未来承诺。

### 数据状态必须可见

- `verified`（已人工最终复核） / `provisional`（研究预览可用，非最终事实） /
  `conflict`（日期存在研究分歧，保留双方口径） / `preview`（Research Candidate 预览）。
- **PROVISIONAL 不得冒充 VERIFIED。**
- **Research Candidate 永不是 Confirmed Historical Campaign。**

### 冲突不得被"自动取舍"

日期口径存在分歧时（如起点 04-27 vs 05-23），
视觉必须**同时呈现双方**（Candidate A / B），不得自动选一个。

## 一句话总结

> **ThreeC 把 A 股历史上的机会放在同一条时间轴上，
> 让你看见"这个时间点历史上通常发生什么"——
> 至于要不要下场，是你自己的事。**
