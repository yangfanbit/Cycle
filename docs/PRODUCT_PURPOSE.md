# PRODUCT_PURPOSE.md — 产品目的

> 本文件定义 ThreeC 最终产品的**是什么**与**不是什么**。
> 与根 `AGENTS.md` §1「项目初心」一致；冲突时以根 `AGENTS.md` 为准。

---

## 产品定义

# 基于历史时间轴的 A 股机会地图

用户打开产品，看到的是**一条历史时间轴**，而不是一张行情表。

---

## 核心（产品做什么）

| 维度 | 说明 |
|---|---|
| **历史时间** | 今天处于一年中的什么位置（TODAY 标记 + 365 天真实比例轴） |
| **主题** | 历史上这个时间附近出现过哪些主题 / 行情 |
| **周期阶段** | 主题如何形成 → 发展 → 转折 → 结束（Lifecycle / Peak Window） |
| **驱动因素** | 为什么启动 / 加速 / 转折 / 结束（Drivers 四问） |
| **提前观察** | 有没有提前信号（Early Signal），哪些方向值得继续研究 |

**产品目标 = 机会发现（长期方向，**效果未验证**）。**

产品帮助用户**发现值得进一步研究的方向**，把"历史怎么走"讲清楚。
发现之后的研究与判断，由用户自己完成。

★★ **「机会发现」是目标，不是已验证的效果。** ThreeC 用于发现**值得进一步研究的 A 股题材线索**，
其**相对于常规研究方法的增量价值仍待验证** —— 目前**没有**对照实验，
也没有任何证据表明「用 ThreeC 找到的线索」优于「不用 ThreeC」。
**不得**把「有这个功能」表述为「这个功能已被证明有用」。

### 三层能力：已实现 / 待验证

| 层 | 内容 | 当前状态 |
|---|---|---|
| ① 历史证据整理 | 历史事件 / 参与标的 / 时间窗口 / 来源与证据等级 / PIT 纪律 | ✅ **已实现** |
| ② 研究线索发现 | 季节性窗口 / 当前观察台 / 方向查询 / 外部线索核验 / 候选追踪 | ✅ **已实现** · ❌ **有效性未验证** |
| ③ 经过验证的预测能力 | 事前特征 + 时间前推 + 基准比较 + 校准记录 | ❌ **不存在** |

> ★ 三层**互不等价**：②有功能不等于②有效；②有效也不等于③已建立。
> 详见 `AGENTS.md` §3.1 与根 `README.md` 的同一张表。

## 非核心（产品明确不做）

- ❌ 基本面分析
- ❌ 技术分析
- ❌ 买卖点 / 入场时机判断
- ❌ 自动荐股 / 选股
- ❌ **未经声明口径**的价格预测 / 收益预测 / 确定性未来预测
- ❌ 买卖信号 / 自动交易
- ❌ 实时行情 / 资金流 / 异动监控
- ❌ 把历史比例写成「未来概率」或「大概率」；把未校准的比例当作精度声明
- ❌ 用户登录 / 权限系统 / 后端

> ★★ **2026-10-18 规则调整（v0.9）后的口径**：原「不做价格预测 / 不做胜率 / 不做概率」的**全局禁令已撤销**
> （以 `AGENTS.md` §3.1 为准）。ThreeC **可以**研究历史频率、条件概率、阶段变化概率与未来窗口预测，
> 但必须写明**口径七要素**（预测目标 / 样本范围 / 观察期限 / 分母 / 排除规则 / 来源 / 不确定性），
> 并以**时间顺序**验证、与**简单历史基准**比较、记录**校准与误差**。
>
> 当前产品里能看到的比例只有一层：**探索性经验基准概率**（`k/n` + 95% Wilson，**未校准**），
> 它**不是**「已验证的预测模型」，也**不是**未来概率。
> ★ 该比例的分母是「**本题材**在**这些年份**里完整可比较的窗口」，
> **不是**「所有可能题材（含从未成势的方向）」的完整观察总体 —— 两者不是一回事。

> UI 文案中「买入 / 卖出 / 建仓 / 清仓 / 推荐」等词，
> **只允许出现在否定性免责声明中**（如"不构成买卖建议"）。

## 关键边界声明

### 用户自己负责入场判断

**ThreeC 不提供、不暗示、不承担任何入场判断。**

- 「提前观察窗口」≠「买入时机」。
- 「历史上这段时期出现过机会」≠「今年会出现机会」。
- 「Early Signal」= 研究层信息，**不是交易信号**。

用户自行负责：基本面研究、技术面研究、个股选择、入场时机与仓位。

### 前瞻性分析 ≠ 确定性预测

**禁止**：确定性未来预测、保证收益、"必涨 / 必跌"、自动交易信号。

**允许**：历史统计、历史相似案例、当前状态识别、时间窗口分析、
历史条件分布、情景分析、前瞻性观察窗口、"提前观察"提示。

即使未来完成统计验证，展示的也是**"历史统计特征"**，不是未来承诺。

### 数据状态必须可见

- `verified`（已人工最终复核） / `provisional`（研究预览可用，非最终事实） /
  `conflict`（日期存在研究分歧，保留双方口径） / `preview`（Research Candidate 预览）。
- **PROVISIONAL 不得冒充 VERIFIED。**
- **Research Candidate 永不是 Confirmed Historical Campaign。**

### 冲突不得被"自动取舍"

日期口径存在分歧时（如起点 04-27 vs 05-23），
视觉必须**同时呈现双方**（Candidate A / B），不得自动选一个。

## 一句话总结

> **ThreeC 把 A 股历史上的机会放在同一条时间轴上，
> 让你看见"这个时间点历史上通常发生什么"——
> 至于要不要下场，是你自己的事。**
