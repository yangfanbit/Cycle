## 4. ThreeC 1.3 目标裁定

> ★ 裁定基准：仓库内「1.3」的**唯一**定义是 Phase **1.3 Product 只读页面**
> （`docs/PROJECT_STATE.md` §版本表：1.3 = Product 只读页面 · 状态 **RELEASED**；
> 目标原文：「基于真实数据 + diff；把『无对应』做成一等公民」）。
> 本节按该定义逐条对照；若任务书里的「1.3」指别的里程碑，以此处的基准声明为准可被纠正。

| 1.3 目标要素 | 裁定 | 证据 |
|---|---|---|
| 基于**真实数据**（非示例/非伪造） | **达成** | 三场景读数为真实静态产物；导出字段与产物逐项一致；`snapshot = MS-2026-10-13-01` 唯一 CANONICAL |
| **diff**（与上期对比） | **达成** | 展开钻取区实测：`MS-2026-10-12-01（2026-10-12）→ MS-2026-10-13-01`，**共 18 处变化**（市场环境 0 / 研究对象 0 / 历史候选 +18 / 观察 0），并明写「只陈述事实，不含好坏判断」 |
| 把「**无对应**」做成一等公民 | **达成** | 场景 ③：`none` 给出「库内 59 主题」+「未覆盖 ≠ 结构上无对应」+ 导出 `matchedTheme=null`，未伪造任何命中 |
| 只读（不写库、不生成对象） | **达成** | 草稿 `id=null` / `status=DRAFT_NOT_REVIEWED` / 仅存本机 `localStorage`，未上传 |
| 完整工作流可走通 | **达成** | 查询 → 结论 → 草稿 → JSON/MD 导出 → 历史地图 PIT 证据，41/41 |

**同时必须记录「未达成」的部分**（属证据体系，不属 1.3 页面目标，但决定产品可信度上限）：

1. **角色研究覆盖 13 / 33 事件**，20 个事件仍是「未研究」——缺**带发布日与 URL 的同期报道**，或未形成连板盘面；
2. **「报道称龙头」= 0**：库内没有任何材料**明确称**某股为龙头，需要同期多篇报道横向比对（新研究轮次）；
3. **2 处身份待人工确认**：PIT CSV 的 `JINJIANG`（注册表为锦江酒店 600754 ≠ 锦江在线）、
   `DAZHONGTONG`（注册表 `DADONGTRAFFIC`）——当前按**名称精确相等 + 唯一参与者**绑定并标
   `NAME_MATCH_ONLY`，未按 ID 硬匹配；
4. **ST 状态不可判定** → 涨停识别为**漏报方向**，不得据此声称「已穷尽」；
5. **2016 白酒段收益仍不可算**（qfq 非正价格，hfq 裁定 NOT_ADOPTED，缺可核验分红/送转记录）。

⇒ **裁定**：**1.3 的页面与工作流目标 = 达成（本轮实测 41/41）**；
**「历史证据体系完备」= 未达成**（13/33 覆盖、龙头认定 0、2 处身份待确认）。
两者不得互相替代：页面能如实展示「未研究 / 未绑定 / 不确定」，正是 1.3 要求的诚实性，
但它**不等于**研究已经做完。

## 5. 验收中发现并修复的缺陷（v0.31.1）

**现象**：把钻取区全部展开后扫描页面文本，发现 **51 处**研究侧 Markdown `**强调**` 被**原样渲染成星号**
（例：`该题材会上涨；「窗口内」只是**时间事实**`、`沪深300 近 20 交易日 **-5.50%**`、
`仅存在**外围**机制交集（PERIPHERAL_OVERLAP）→ **不计入**结构支持`）。

**根因**：这些字符串来自研究侧 JSON（`mapping.basis` / `source_note` / `regime.beta_note` /
`observations[].claim` / `why_not_similar[]` / 驱动标签 / `oneLiner`），渲染时**没走 `RichText`**，
而 JSX 里手写的 `**…**` 也不会变成 `<strong>`。这是本项目已知陷阱的**复发**（v0.28 曾修过同类问题）。

**修复**（只改**渲染侧**，**不改研究产物**）：

| 位置 | 处理 |
|---|---|
| `ExternalSeasonalRadar`（映射依据 / 未映射原因 / 不确定性） | 过 `<RichText>` |
| 雷达页脚、`App` 分类体系说明、`App` 溯源说明 | 手写 `**…**` → `<strong>` |
| `CurrentSnapshotSection`（`beta_note` / `why_similar` / `why_not_similar` / `observations[].claim`） | 过 `<RichText>` |
| `CurrentTimeLens`（驱动标签 chips / Layer A·B·C note） | 过 `<RichText>` |
| `CurrentCandidateSection`（提示语 / `oneLiner`） | 过 `<RichText>` |
| `CampaignDetail`（`why_not_similar[]`） | 过 `<RichText>` |

**结果**：同一扫描口径（整页展开）**51 → 0**。
**防回归**：新增页面级不变量测试 `src/components/__tests__/rawMarkdownRendering.test.tsx`
（挂载真实 `<App />` + 真实数据，对整棵渲染树做 `\*\*[^*\n]+\*\*` 扫描）。
★ 已做**负向对照**：临时还原一处裸星号 → 该测试**失败**；还原修复 → **通过**（证明断言有判别力，
不是无条件成立）。
