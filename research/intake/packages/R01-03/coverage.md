## 1. 本任务覆盖了什么

本任务研究 **资源 / 有色 / 化工**（工业金属、贵金属、稀有金属、能源金属、基础化工、农化）在 2015–2025 年的历史结构候选。

**目标不是寻找历史「同名主题」，而是寻找具有明确启动窗口、发展过程、形成机制，并能作为历史结构比较对象的候选。**

共提交 **11 个候选**，机制刻意保持差异：

|---|---|---:|---|---|---|---|

```text
行政去产能        → C10（2017 电解铝）
能耗双控行政限产  → C4（2021 基础化工）
环保约束          → C11（2016 化工，商品端成立 / A 股端 INSUFFICIENT）
配额型供给约束    → C3（2021 稀土）
安全事故型供给冲击 → C5（2019 染料/中间体）
```

以及三条非供给收缩型的资源品机制：全球流动性 + 需求复苏（C1）、新能源需求拉动（C2）、成本冲击 + 出口限制（C8）、矿端结构性缺口（C9）。

## 4. 证据纪律执行情况

### 4.1 五类信息严格分离

| 类型 | 记录位置 | 示例 |
|---|---|---|
| **商品价格** | `evidence`（商品口径） | E001 LME 铜 10747.5 美元/吨；E012 碳酸锂 59 万元/吨 |
| **行业基本面** | `evidence`（行业文件） | E002 有色协会产量/利润；E021 稀土年度均价 |
| **政策事件** | `evidence`（官方文件） | E031 发改委双控文件；E091 四部委电解铝通知；E032 云南限产通知 |
| **市场表现** | `evidence`（行情数据） | E007 中证有色指数 +31.31%；E015 能源金属指数 +62.50%；E105 基础化工 -7.13% |
| **公司与证券事实** | `securities` + `evidence` | SEC021 浙江龙盛 2019-03-22 一字板；SEC006 云铝股份减少 77 万吨产能 |

### 4.2 关键纪律：商品涨 ≠ A 股主题启动

本任务用证据链专门建立「商品 / 行业变化 → A 股市场扩散」的时间关系，并**保留了两个明确的反例**：

- **CF010 / C11**：2016 年化工商品价格 +29.84%（指数 618→833），同期申万基础化工板块 **-7.13%** → 商品涨而 A 股板块未启动。
- **CF009 / C7**：2025 年 12 月金价创历史新高（4526 美元/盎司），但 A 股金矿龙头股价**未同步创新高**。
- **C8 农化不作反例**：唯一板块级证据 E075 显示化肥概念板块 2021 年 **+24.24%**（峰值 2021-09-28），板块响应客观存在；但该证据仅覆盖 2021 年、早于商品 peak 窗口（2022-03—2022-04）约半年，且 C8 全部 evidence 均为事后口径，故其商品→A 股传导**「证据不足 / 无法确认」**，不作为反例使用。

### 4.3 Point-in-Time 防火墙

- 每条 evidence 均标注 `temporal_relation` 与 `support_kind`。
- 凡 `subsequent` / `retrospective` 证据均填写 `point_in_time_note`，明确其不得充当启动或主升的同期催化。
- 年度涨幅（2021 行业涨幅、2024 金价均价等）一律标记为 `subsequent`，**不得**用于证明当时已知。
- `securities` 中逐条区分 **Historical Leader Set（retrospective）** 与 **Point-in-Time Basket**，并标记 `survivorship_aware`。

### 4.4 证据独立性

- 使用 `independence_group`；同源转引标记 `retelling` / `primary_source`。
- 例：E005（央视网）与 E006（中国经济网）虽给出同一组行业涨幅，但来源独立，分属 `IG-CCTV-2021A` 与 `IG-CECN-2021A`。
- 例：E021–E023 同源于中稀稀土研究院同一文件，共用 `IG-CREOL-RE`，不虚增独立证据数。
