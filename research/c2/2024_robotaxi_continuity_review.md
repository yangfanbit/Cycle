## 8. 连续性判断

对照框架：

| 判据 | 09-05/06 回流 |
|---|---|
| 原主题是否明显消失 / 是否有冷却期 | 有：08-23 跳水后约 2 周冷却（EW 阴跌至 180）→ 符合“明显退潮 + 冷却期” |
| 新催化剂是否与原一轮不同 | **是**：新出现“特斯拉 FSD 入华预期”主线，叠加 Robotaxi 10 月 + 萝卜快跑扩容（非 7 月“萝卜快跑武汉出圈”同一单项） |
| 是否再次形成同步行情 | 部分：3/5 核心同步 + 新面孔，但 AutoETF/HS300 未动、且 2 日内回吐 |
| 持续性 | **差**：09-05/06 两日后 09-09/10 完全回吐，无持续 |

**结论：`secondary_campaign_same_theme_cycle`（同一 Theme Cycle 下的次级/echo Campaign，弱）。**
- 更符合“新催化剂 + 冷却期 + 部分再同步” → 相同 Theme Cycle 的**次级再启动**，而非原有 Campaign 的连续延伸（有约 2 周断档）。
- 但因**仅 3/5 核心 + 2 日即回吐、无板块级共振**，强度弱，且部分个股特征明显——**不判 New Campaign，也不降为 pure individual_rebound**（有多个核心同步 + 明确主题催化）。
- 标注：若人工认为“仅大众/锦江/金龙、缺星网/天迈”权重过高，也可更保守地归 `unclear`；本复核以多核心 + 明确主题催化，取 `secondary_campaign_same_theme_cycle`。

## 9. 08-23 的最终含义
- **08-23 = 主升段后的重大 Breakpoint / 主 Campaign End Candidate（不是 Final Theme End）**。
- 由历史核心 EW 看，主升峰值 08-05、First Decline 08-06、08-23 跳水后进入约 2 周冷却 → **08-23 更像“Main Campaign 结束边界”**。
- 但 09-05 的 Reactivation 表明**主题并未在 08-23 终结**，而是 9 月进入**同主题次级/echo 段**。
- 因此：**08-23 定为 Main Campaign End（或 End Candidate），主题 Cycle 延续至 09-05 的次级段**；是否把 09-05 另立为 Secondary Campaign，待人工决定。

## 10. 07-09 vs 07-10 Start Confirmation
- 重新措辞（区分 Point-in-Time 与 Retrospective）：
  - **07-09**：是**首个指数大阳日**（Historical Leader EW +10%），但当时 Point-in-Time 能可靠识别的 theme 归属有限（大众 market_breadth、锦江/星网 media 初确认），且**当时并无明确“广泛主题催化”的单点实据** → 属 **Retrospective Confirmation / 事后增强**。
  - **07-10**：天迈获**当日证券时报点名**（high）、萝卜快跑“跑出圈”媒体全面发酵，核心股数量与主题归因在当日都更充分 → **更符合 Broad Theme Confirmation（Point-in-Time 更可辩护）**。
- 建议措辞：**Start 起势 07-08 → 首个 Index 大日(R) 07-09 → Broad Theme Confirmation（PIT 可辩护）07-10**。不再把 07-09 单称“Point-in-Time 广泛确认日”。

## 11. 数据模型是否需要 Theme Cycle（仅建议，不改 schema）
- 建议：在**不重建核心 schema** 的前提下，用一个 **research-level 标签/文件**记录“theme_cycle 与 sub-phase 边界”（如 `theme_cycle_id=robotaxi_2024`，sub-phase=main/secondary/dead）。等 ≥2 个 Campaign 验证后，再评估是否引入正式 `theme_cycles` 表。
- 理由：本轮 08-23（main end）与 09-05（secondary）说明一个主题内部可含**多个主/次级 Campaign**，当前 `campaigns` 单行无法优雅表达“Cycle 内含多段”；但不宜本轮改库。
