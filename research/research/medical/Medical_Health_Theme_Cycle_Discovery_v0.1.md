# Medical Health Theme Cycle Discovery v0.1

> **性质**：Research-level 发现报告（Theme Cycle Discovery）。**不是**数据库录入、**不是**代码变更、
> **不是** Campaign 创建、**不是**行情复盘。
> **唯一目标**：验证 ThreeC Research Model 能否从汽车扩展到第二个 Macro Theme —— **医药健康**，
> 并判断 2018–2022 是否存在一个**可定义的 Theme Cycle**、内部是否存在 **Campaign Candidate**。
> **日期**：2026-09-14 ｜ **范围**：2018–2022（允许边界漂移，由证据决定）
> **纪律**：PIT 视角 · 区分事实与解释 · 不预测 · 不构成买卖建议 · 不用后来涨跌作唯一证明 · 未知即标 `Unknown`。
> **本轮不改** schema / DB / export / 历史结论 / Campaign。

## 0. 数据来源与限制（必读）

**本报告的证据结构，以及它的边界：**

| 证据类型 | 状态 | 说明 |
|---|---|---|
| **政策 / 监管官方事实** | ✅ 可用（Tier 1–2 来源可核） | 4+7 集采、医保谈判、集采扩围等，有官方与主流媒体公开记录 |
| **行业景气数据（研发投入、CRO 收入增速等）** | ✅ 部分可用 | 来自当期券商研究与年报摘要，属 Tier 3 |
| **当期市场评论（公募/券商）** | ⚠ 可用但属**解释** | 用于还原"当时市场在想什么"（PIT 认知），**不能当作事实** |
| **ThreeC 行情数据库** | ❌ **不可用** | `cycle_research.db` 的 32 条 `market_series` **全部为汽车**，**医药方向 0 条** |
| **医药指数/个股行情（精确点位与区间收益）** | ❌ **不可用** | 无本地数据源；本报告中出现的年度涨跌幅来自公开报道，标注为 **二手数据**，未做本地复核 |

> **由此产生的硬限制（必须贯穿全文）**：
> 1. 任何"什么时候启动/见顶"的判断，**不能**用精确行情点确认 → 一律标 **`Unknown / 待数据验证`**。
> 2. Gate 的 **Q3（持续性）与 Q4（生命周期）无法用本地数据验证** → 只能用"当时公开叙事 + 年度涨跌幅（二手）"近似
>    → **因此 Campaign Candidate 的置信度上限为 `medium`，最高不超过 `medium`。**
> 3. 本报告的作用是 **模型可行性验证 + 候选假设生成**，**不是**结论性研究。

## 1. Executive Summary

**一句话判断：**

> **医药健康存在一个可定义的 Theme Cycle** —— 其核心叙事是
> **「中国医药产业从仿制药/销售驱动，转向创新驱动 + 产业链专业化」**，
> 时间上约 **2018Q4（Setup）→ 2019（Formation/Confirmation）→ 2020–2021H1（Expansion）
> → 2021H1/H2（Peak，子行业分批见顶）→ 2021H2–2022（Decline / 估值出清）→ 2022 年末（修复迹象，未确认结束）**。

**内部结构判断（关键）：**

| 判定项 | 结论 | 置信度 |
|---|---|---|
| 是否存在 Theme Cycle | ✅ **存在**（Case 判定见 §3.4） | medium |
| 属于 §七 的哪一种情况 | **倾向 情况 B**（一个 Theme Cycle + 多个 Campaign，允许 overlap）；**不是 A**（不止一个大 Campaign），**不是 C**（不是多个互不相关的短期行情） | medium-low |
| 是否可直接复用汽车模型 | ✅ 可以，且**暴露 3 个新问题**（见 §8.2） | — |
| 是否需要改 ThreeC Research Model | ❌ **不需要**（新问题均可在既有分层内表达，见 §9） | — |

**最重要的单条发现：**

> 汽车是「**一个 Macro Theme（汽车）→ 多个按年/按题材切分的 Campaign**」；
> 医药健康是「**一个 Theme Cycle 内部，多个 Sub-theme 有各自节奏、分批见顶**」。
> 两者**结构相同、形态不同**：汽车是**纵向时间分期**，医药是**横向叙事并存**。
> 这正是「Macro Theme → Theme Cycle → Campaign → Sub-theme」分层的价值所在 ——
> **它同时装得下这两种形态。**（详见 §8.1）

## 2. Macro Theme Definition

### 2.1 为什么「医药健康」属于 Macro Theme

按 `theme_campaign_separation_v1.md` §1 的定义：Macro Theme = **产品级长期稳定分类**，
不随年度题材轮动而改变，具备长期存在的产业结构与需求基础。

**医药健康满足：**

| 判据 | 医药健康 |
|---|---|
| 长期稳定分类（不随年度题材变） | ✅ 无论当年炒创新药/CXO/中药/器械，底层都是"医药健康" |
| 有独立的产业结构 | ✅ 制药 / 生物制品 / 医疗器械 / 医疗服务 / 医药流通 / 中药，产业结构稳定 |
| 有独立的需求驱动 | ✅ 人口老龄化、疾病谱、医保支付、技术进步 —— 与汽车（可选消费 + 制造）**完全不同源** |
| 已有基础政策锚点 | ✅ 三医联动（医保/医疗/医药）、集采、医保谈判、审评审批改革 |
| 与「汽车」不重叠 | ✅ 无题材交集 |

### 2.2 与既有代码/数据的一致性

| 层 | 医药健康现状 | 结论 |
|---|---|---|
| 产品主题树 `data/candidate/themes.ts` | ✅ `th_pharma 医药`（`theme_type='sector'`, root，无 parent） | **已按 Macro Theme 注册** |
| 产品规则层 `data/candidate/rules.ts` | ✅ `rule_pharma_post_interim`（中报后医药窗口 08-15~09-30, candidate） | 已存在 |
| 研究候选 `rule_candidates_v1.md` | ✅ `rule_pharma_year`（候选 #2，风险栏：「**主题分散，需按子赛道拆窗口**」） | 已存在 |
| research DB `themes` / `campaigns` | ❌ 0 条 | **无研究数据** |
| export | ❌ 0 条 | 无 |

> **结论**：作为 **Macro Theme 是合格的**，且**产品层已预留**。
> 但**研究层完全空白** —— 本报告是该方向的第一份研究材料。

## 3. Theme Cycle Candidate

### 3.1 名称与时间

| 项 | 内容 |
|---|---|
| **候选名称（research-level）** | `medical_structural_upgrade_2019_2022` |
| **替代命名** | `pharma_innovation_upgrade` / `medical_industry_revaluation` |
| **核心叙事** | 中国医药产业**从仿制药与销售驱动，转向创新驱动 + 产业链专业化 + 国际化**；医保从"支付方"转为"战略购买方"，倒逼行业结构升级 |
| **时间** | **Start Setup 2018Q4 → 2022 年末（未确认结束）** |
| **跨度** | 约 4 年（**跨多年**）→ 与 Theme Cycle「可多年」的既有定义一致 |

### 3.2 生命周期（候选，全部标 PIT 可得性）

| 阶段 | 时间（候选） | PIT 当时可得的依据 | 置信度 |
|---|---|---|---|
| **Start / Setup** | 2018Q4（约 2018-12） | 4+7 集采冲击；市场对仿制药商业模式产生根本性质疑。**Setup 的特征是"旧叙事被摧毁"，而非"新主题被确认"** | medium |
| **Formation** | 2019Q1–Q3 | 科创板（2019-07 开板，生物科技未盈利上市通道）；医保局体制确立；市场开始区分"创新"与"仿制" | medium |
| **Confirmation** | **2019-11-28** | 国家医保谈判结果公布：150 谈成 97，新增 70 个**平均降幅 60.7%**；**PD-1 首次纳入医保**；**"12 个国产重大创新药谈成 8 个"** → 官方明确释放"**鼓励创新**"信号 | **high** |
| **Expansion** | 2020Q1–2021H1 | 疫情放大医药关注度；全球流动性宽松；CXO 景气持续；公募持仓与估值中枢上移 | medium |
| **Peak（分批见顶）** | 2021-07-01（板块口径）→ 2021Q4/2022-01（成长赛道口径） | 多来源指向 **2021-07-01 为板块高点**；创新药概念指数高点落在 **2022-01-04**（口径差异，见 §3.3） | medium |
| **Decline** | 2021H2–2022 | 集采范围扩大至消费医疗/器械/IVD；高估值消化；**资金风格切向新能源（电新/有色/钢铁）** | medium |
| **End** | **未确认**（2022 年末出现修复迹象，不足以判定 Cycle End） | 2022 年末 PE 降至近 10 年低位区间；10 月起政策预期转暖 | `Unknown` |

### 3.3 ⚠ 一个必须记录的**口径问题**（重要）

不同指数口径给出**不同的顶**：

| 口径 | 报告中的高点 | 含义 |
|---|---|---|
| 板块口径（大盘医药为主） | **2021-07-01** | 消费医疗 / 器械 / 服务 先见顶 |
| 成长口径（创新药概念指数） | **2022-01-04** | 创新药 / CXO 等成长赛道**滞后约半年**见顶 |

> **这不是矛盾，而是证据**：它说明 **Sub-theme 各有独立节奏** ——
> 这正是"医药是横向叙事并存、而非纵向时间分期"的直接体现。
> **同时它也是一个方法论提醒（→ 反馈给模型）**：
> **Campaign 的 Peak 必须以"该 Campaign 自己的代表标的/子指数"为口径，不能用全板块指数代替。**
> 汽车案例中 `2022_auto_boundary_review.md` 已用「龙头峰值 vs 行业代理峰值分列记录」处理过同类问题 ——
> **这套做法可以直接复用。**

### 3.4 情况判定（§七 的 A / B / C）

| 情况 | 定义 | 是否成立 | 依据 |
|---|---|---|---|
| **A** | 一个 Theme Cycle：一个大 Campaign，内部多个 Sub-theme | ⚠ 部分成立 | 2019–2022 确实存在一条共同主线；但**疫情医疗**的龙头组与驱动与主线**明显不同源**，压平成一个大 Campaign 会损失信息 |
| **B** | 一个 Theme Cycle：多个 Campaign（可 overlap） | ✅ **倾向成立** | 疫情医疗（2020–2021）与创新药/CXO 主线（2019–2021H1）**时间大幅重叠、叙事与龙头均不同** → 符合"同一时间 ≠ 同一个 Campaign" |
| **C** | 不存在连续 Theme Cycle，只有多个短期行情 | ❌ 不成立 | 存续期约 4 年、跨年、有明确的政策-产业-资本三层驱动，**不是短期行情集合** |

> **判定：倾向 情况 B**，但置信度 **medium-low** ——
> 因为 Q3/Q4 缺乏本地行情数据支撑（见 §0）。**需要在录入医药行情数据后复核。**
> **本次不把任何候选写成 Campaign**（遵守任务约束）。

## 8. ThreeC Compatibility Review

### 8.1 Q1：汽车模型是否可以直接复用？

**✅ 可以直接复用，且复用度很高。**

| 汽车案例的机制 | 医药能否直接套用 | 说明 |
|---|---|---|
| Macro Theme → 多个 Campaign | ✅ | `th_pharma 医药` 已是 root 主题 |
| Theme Cycle = research-level 标签（不入库） | ✅ | `medical_structural_upgrade_2019_2022` 可用同一机制 |
| Research Signal（EARLY_SIGNAL / THEME_FORMING / CONFIRMATION_CANDIDATE） | ✅ | 医药的 2018Q4 / 2019 / 2019-11-28 可分别映射 |
| Campaign Phase（lifecycle） | ✅ | 但需注意口径（见下 P1） |
| Campaign Overlap 允许 | ✅ | M1 与主线大幅重叠 |
| Theme Drift | ✅ | 主线内部经历 创新药 → CXO → 出海 的叙事漂移 |
| **Campaign Independence Gate（Q1–Q5）** | ✅ | **本轮已实际使用**，且有效区分了 Case A / B |
| **Peak 分列口径**（龙头 vs 行业代理） | ✅ **可直接复用** | 正好对应医药的"板块 2021-07-01 vs 成长 2022-01-04" |

> **结论：汽车模型可以直接复用。** 汽车是「**纵向时间分期**」（一年一个 Campaign），
> 医药是「**横向叙事并存**」（同一 Cycle 内多叙事分批见顶）——
> **同一套分层同时装得下这两种形态**，这正是分层的价值。

### 8.2 Q2：医药是否暴露新的模型问题？

**✅ 暴露 3 个新问题（均为"表达/口径"层，非"需要新实体"层）：**

| # | 新问题 | 说明 | 影响 |
|---|---|---|---|
| **P1** | **Campaign Peak 的"口径归属"需要显式规则** | 医药出现「板块顶 2021-07-01」与「成长赛道顶 2022-01-04」的**半年错位**。若沿用单一板块口径，会把 Sub-theme 的节奏差误判为 Campaign 边界。汽车已有解法（龙头 vs 代理分列），但**规则未上升到通用判据** | 建议：在 `theme_campaign_separation_v1.md` 补一句「**Peak/End 应以该 Campaign 自己的代表标的或子指数为口径，不得用上位板块指数代替**」 |
| **P2** | **"共享资金池"导致的伪独立性** | M2（消费医疗）与主线同属"医药核心资产"资金池，导致 Q1（独立注意力中心）**难以判定**。汽车案例中未遇到此类问题 | 建议：Gate 的 Q1 需补一个**反例提示**：「若两个候选共享同一资金池/同一持仓逻辑，Q1 倾向否」 |
| **P3** | **Macro Theme 内部可能出现"准 Macro Theme"**（中药） | 中药在 2021–2022 有独立政策 + 独立节奏（+31.71% / 抗跌），且**中医药有独立的产业与政策体系**。它究竟是「医药健康」下的 Sub-theme，还是应独立为 Macro Theme「中医药」？ | **这是需要人工决策的模型边界问题**；本轮**不擅自决定**，标记 `Unknown` → 交人工 |

### 8.3 Q3：是否需要修改 ThreeC Research Model？

**❌ 不需要。**

理由：

1. **三个新问题都不需要新实体、新表或新字段**：
   - P1 是**口径规则**（补一条判据，不新增数据）
   - P2 是**Gate 的反例提示**（补一句，不加字段）
   - P3 是**归组决策**（`themes.parent_theme_id` 已能表达两种归属，只差人工选定）
2. **分层结构未受挑战**：Macro Theme → Theme Cycle → Campaign → Sub-theme → Phase/Signal
   在医药上**首次被完整使用且未出现装不下的情况**。
3. 符合 `research_model_v1_0.md` §18 的冻结纪律：
   **判据补充 ≠ 模型扩展**。
