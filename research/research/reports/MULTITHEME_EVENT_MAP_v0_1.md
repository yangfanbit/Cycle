## 二、通用事件地图（`HistoricalEventMap`）

### 2.1 改造内容

| 项 | 改造前 | 改造后 |
|---|---|---|
| 数据 | 硬编码 `import flu_...v0_4.json` | **索引 + 静态注册表**（`historical_event_maps_index.json`） |
| 事件类别 | 硬编码 `FLU_DIRECT / ADJACENT_PUBLIC_HEALTH` | **由题材 `event_classes` 提供**（校验从数据读取） |
| 免责声明 | 硬编码流感文案 | **题材 `display.class_caveats`** 提供；★ 三条**跨题材通用**声明仍为代码常量 |
| 接入 | `EVENT_MAP_IDS = ['EXT-12']` | ★ **数据驱动**：按索引的 `external_entry_ids` 匹配 |
| 组件 | `FluEventMap` 单文件 | `HistoricalEventMap`（通用）+ `FluEventMap`（薄封装） |

### 2.2 未丢失的既有语义（有测试保护）

- 事件类别区分 + 邻近事件免责声明
- `evidence_level` 与 `category` **分离**（业务机制核实**不**改 category）
- 「行情不可得」显式标注（不显示为 0 涨幅）
- 三条通用免责声明（业务机制时间边界 / 行情非 Campaign 裁定 / 邻近事件不得作季节性证据）
- `corrections` 更正痕迹；负面参照（联环药业澄清）不被隐藏
- 四个流感事件**展示零变化**（薄封装 + 索引 `display` 复刻原文案）
