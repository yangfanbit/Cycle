# Rule Candidates v1（第一批 Opportunity Map 候选规则）

> 状态：**Rule Candidates（研究候选）**，不是"已确认有效"的规则。
> 依据：已有较多历史经验资料 + 存在明显时间规律 + 容易形成时间轴。
> 纪律：在逐个验证前，**不假设它们一定有效**；不新增正式 Schema；当前仍只对 `rule_auto_summer`（汽车）做批量生产。

## 第一批 Rule Candidates（3–5 个）

按"资料可得性 + 时间规律显著性 + 时间轴可表达性"筛选，候选来自现有研究材料中提及的行业池（电力 / 医药 / 消费 / 传媒广电 / 纺织服装）：

| # | rule_candidate_id | base_pattern | 候选观察窗口 | 理由（为何可能形成时间轴） | 主要风险 |
|---|---|---|---|---|---|
| 1 | `rule_power_summer` | 电力 / 绿电 | 夏季（迎峰度夏 6–8 月） | 用电高峰季节性明确 + 绿电/电价改革政策驱动；历史数据与新闻资料丰富 | 板块波动受煤价/电价机制影响，题材性弱于行业性 |
| 2 | `rule_pharma_year` | 医药（创新药 / 中药 / 集采） | 全年多窗口（医保谈判 Q4 / 集采 / 创新药出海催化） | 政策周期（医保谈判、集采、审评）时间规律强；历史经验资料极多 | 主题分散，需按子赛道拆窗口 |
| 3 | `rule_consumer_holiday` | 消费（白酒 / 食品饮料） | 节假日前后（春节 / 国庆 / 618 / 双11） | 节假日消费数据与行情联动明显，时间轴天然（日历事件） | 与大盘 β 相关性高，需分离市场因素 |
| 4 | `rule_media_cycle` | 传媒 / 广电（游戏 / 影视） | 暑期档 / 游戏版号周期 | 版号发放、暑期档、电影档期事件驱动强，事件时间轴清晰 | 政策监管（版号）不确定性高 |
| 5 | `rule_textile_export` | 纺织服装 | 春夏/秋冬换季 + 出口数据窗口 | 出口景气数据 + 季节订货会 + 冷冬/暖冬主题，事件可追溯 | 行情多以个股/小盘脉冲为主，板块级别 Campaign 较少 |

## 评估门槛（进入正式研究前必须回答）

对每个 Rule Candidate，做**产品初心四问**（product_purpose_checkpoint.md）：

1. 是否帮助构建时间轴？（能否回答"这个时间点历史上通常发生什么"）
2. 是否提高历史可比性？
3. 是否有助于识别提前信号？
4. 是否只是工程复杂化？

未通过 → 停止，仅记录为 Research Limitation。

## 下一阶段建议（不阻塞本轮）

1. 保持 `rule_auto_summer` 为唯一批量生产规则，先把 2018–2025 Auto 的 Phase Windows + Drivers 做完整。
2. 从本表 5 个候选中挑 1–2 个做**轻量 Pilot**（先只建 2018–2025 时间轴骨架 + Rule Candidate 观察，不全面生产）。
3. 任一候选进入正式生产前，须先确认有真实历史行情数据源（AUTO_SW 教训：无数据则如实 unavailable）。
